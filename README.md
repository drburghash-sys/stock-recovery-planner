# مخطط استرداد خسائر الأسهم

تطبيق ويب عربي لحساب سيناريوهات التعامل مع مركز سهم خاسر بدون إضافة سيولة جديدة.

## الوظائف
- إدخال السهم الحالي والكمية ومتوسط التكلفة والسعر الحالي.
- اختيار نسبة البيع: 25% أو 50% أو 75% أو خروج كامل، أو أي نسبة يدويًا.
- إضافة عدة شركات/صناديق بديلة وتوزيع حصيلة البيع بينها.
- إدخال نمو السعر وعائد التوزيعات المتوقع لكل بديل.
- حساب قيمة المحفظة، المبلغ المسترد من الخسارة، والخسارة المتبقية بعد 1 إلى 5 سنوات.
- حفظ الخطة محليًا على الجهاز.
- دعم PWA والتثبيت على الجوال.

## GitHub Pages
يمكن نشر التطبيق من الفرع main والمجلد root.

> الأداة حسابية للمقارنة بين السيناريوهات. العوائد المدخلة افتراضات وليست ضمانًا أو توصية استثمارية.
